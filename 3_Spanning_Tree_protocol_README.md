Spanning Tree Protocol (STP)

What is STP?

STP (Spanning Tree Protocol) is a Layer 2 protocol used to prevent network loops when switches have redundant connections.

STP logically blocks one of the redundant paths while keeping it available as a backup.


Without STP, redundant links can create switching loops and broadcast storms.

Why Use STP?

Prevents Layer 2 switching loops
Prevents broadcast storms
Provides path redundancy
Automatically blocks redundant paths
Provides an alternate path if the active path fails
